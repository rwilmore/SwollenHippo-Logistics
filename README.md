SWOLLEN HIPPO LOGISTICS

---How to execute the program---
- Have python installed on your machine
- Have git bash installed if using a windows based machine
- Using terminal or git bash, locate the file's location
- To locate the file's location use "cd (location of the file)" to change the directory to the correct directory that "main.py" is located 
- Then execute the command "python3 main.py"

---Relevant Information---
- The main menu will only allow you to choose from options 1-6
- An input cannot be blank
- After every function is complete, you will be returned to the main menu
- To exit, press 6 in the main menu
